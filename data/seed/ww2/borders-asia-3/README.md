# 亞洲第三批：南亞、阿拉伯半島、英屬婆羅洲、帝汶、新幾內亞、澳洲、澳門與廣州灣（1937-07-07～1945-09-02）

填補亞洲與太平洋剩下的空白。只寫入開發庫（5442 / 5052 API）；送出前先 pg_dump 備份並 dry-run。

## 內容
- B1：OHM 來源 1 筆、新政權 32 個、事件 6 個（都是**待查證**：未找到正式出處，日期依 OHM 與通行說法）。
- B2：先撤回中華民國 3 筆紀錄並扣掉廣州灣後重送；再新增 36 筆主權／非主權紀錄：
  - 南亞：英屬印度（各省與土邦合為一筆，OHM 未分；1942-03-23 前含安達曼與尼科巴），錫蘭、馬爾地夫、尼泊爾、不丹、阿富汗、法屬印度、葡屬印度，日本佔領的安達曼與尼科巴（1942-03-23 起）。
  - 阿拉伯半島：沙烏地阿拉伯、葉門、亞丁殖民地、亞丁保護地、馬斯喀特與阿曼（含瓜達爾）、特魯西爾諸國、卡達、巴林、科威特（含沙科中立區）。沙伊中立區維持在既有伊拉克紀錄裡。
  - 婆羅洲：砂拉越、汶萊（到 1941-12-16）、北婆羅洲（到 1942-01-02），之後由日本佔領（納閩 1942-02-15 起併入）。
  - 帝汶：葡屬帝汶到 1942-02-20，之後日本佔領（OHM 記 1943-02-10，本表依登陸日，待查證）。
  - 新幾內亞與澳洲：澳大利亞全境、巴布亞、新幾內亞委任統治地；新不列顛與新愛爾蘭 1942-01-23 起日本佔領（以經緯框取出，方法近似）；英屬索羅門群島。
  - 葡屬澳門（全期，中立）、廣州灣（法國租借地，非主權；1943-02-21 起日本佔領）。
- B3：佔領歸屬 5 筆（日本 → 安達曼、英屬婆羅洲、葡屬帝汶、新不列顛、廣州灣）；撤回泰英交戰並重送，地點方法改為「開戰地點：泰緬邊境美塞」。

## 未分段（已知缺口）
新幾內亞本島北岸、海軍部群島、布干維爾、索羅門群島的日本佔領；布納—戈納；英帕爾—科希馬；1945 年澳軍收復婆羅洲；土邦個別邊界。

## 重建
```
cd build && python3 fetch.py && python3 ohm_geoms.py && python3 build_asia3.py
```
`../exp_asia3.json`（開發庫唯讀匯出）與 `../raw/`（Overpass 原始回應）不進版控。

`tools/send_seed2.py --dir requests/B1 … --ids .dev/sent-ids.borders-asia-3-dev.json --derived asia3-derived.geojson`
