# 資料來源規則（操作版）

規則本文是 `docs/source-rules.md`，政策資料是 `data/source-policy.json`。本檔只是操作步驟；有出入時以規則本文為準。規則的改動要由 Tai 在憲法（`.claude/constitutions/world-line.md`）拍板，不要自己放寬。

## 每一筆資料都分開回答四件事，不互相換算

1. **來源等級**：這份出處本身是什麼。A＝當事機關的原始文件或國家級權威機構的編纂物；B＝具名學者或學術機構的研究、第三方當時的官方紀錄；C＝合法、具名，但不到 B；X＝不收。評的是你**實際讀到的那份文件**，不是它引用的書。等級不因來源數目更動。
2. **授權**：只管圖形與圖片能不能放進產品（公有領域或 CC 才行）。引用事實與 80 字以內的引文不受限。
3. **獨立來源**：同機構、同底稿、互相轉引的算同一個家族。涉及敵對雙方的資料，記下來源是己方、對手方或第三方。
4. **可信程度**：已查證＝一筆 A 或兩個獨立家族的 B；待查證＝有 A／B 但不到門檻；推估＝讀圖、內插、文字地名連線；說法衝突＝兩個都留；查無＝不寫入。

## 一定要守的

- 沒有出處的資料不寫入。查不到就照實標「待查證」或記缺口，寫明試過哪些來源、卡在哪裡。
- 不用預設值填空，不自己在兩個說法之間選一個。
- 資料集（OpenHistoricalMap 等）只是幾何來源，不是「這條疆界哪一天生效」的出處。
- Wikipedia、Wikidata 只能當索引找候選值，值要另外用 A／B 來源核對。
- 關於某一方的事實只有對手方出處時，不論等級都是待查證。
- 一件事和它的精確日期、地點、數字分開判定；支持較少的欄位降低精度或列為候選，不整筆丟掉。
- 每筆引文都要逐字出現在存檔的原文裡。
- 禁用網域只看 `data/source-policy.json`，不要在程式裡另寫清單。
- 批次工作若被用量上限或錯誤中斷，產出不提交，重跑到正常結束。

## 每類資料的最低等級

戰役、疆界、控制、政權、事件、首都、元首任期、一般人物生平：A／B。陣營：A。將領生平：可到具名 C（畫面標示等級）。

## 交付前自己檢查

```
python3 -I tools/source_audit.py                      # 全專案稽核（唯讀）
python3 -I tools/source_audit.py --list 違規           # 列出違規的檔案
python3 -I tools/battles/verify_quotes.py <battle>    # 戰役引文逐字核對
python3 -I tools/battles/crosscheck.py <battle> --apply   # 戰役可信程度
```

稽核回傳非 0 表示有違規（禁用網域等），要先處理。「落差」是資料表還沒有等級或出處欄位，新資料不要再增加落差。

戰役的完整流程與交付格式見 `demos/battle-v2.5/DATA-WORKFLOW.md`。
