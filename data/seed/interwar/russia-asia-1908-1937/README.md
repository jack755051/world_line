# 俄國 1908～1925 國界補完整＋亞洲鄰國 1908～1937＋伊朗 1939～1945 東部補完整

**只寫本機開發庫**（worldline-borders-dev，API 127.0.0.1:5052，DB 5442）。正式庫 appdb_ww2（5051）未動；要寫正式庫須另取得 Tai 同意。
寫入前備份：`~/01_Projects/world_line_backups/worldline_borders_dev-before-russia-unclip-20261101-130924.dump`。

## 問題
1926 年以前的俄羅斯帝國、臨時政府、蘇俄、蘇聯紀錄（31 筆）與 1939～1945 伊朗、英蘇佔領伊朗（4 筆）幾何被 WW1／兩次大戰之間批次的試驗框 `box(-20,15,60,72)` 裁在東經 60 度，中亞、西伯利亞、遠東與伊朗東部缺漏。

## 做法（同 unclip-su-tr：撤回再新增）
- 框內幾何沿用原紀錄（含原本扣掉的佔領區）；框外取同一 OHM 固定版本全球重組（Natural Earth 10m 陸地裁切；海岸簡化 0.02°，與鄰國陸界 0.05° 內用 0.0005° 原幾何，鄰國扣除後不留縫）。
- 依指示改用的 OHM 版本：俄羅斯帝國 2849760（～1914-04-17）、2851294（～1916-09-20）、2851158（～1917-09-14）；俄羅斯共和國 2869933；蘇俄 1920-01-01～1920-04-06 用 2851272；其他蘇俄／蘇聯版本不變。換版段：新版框內幾何扣除原紀錄已扣掉的部分。
- 帝國起日改為 1908-10-05。
- OHM 2849760、2851294、2850854、2957452、2959041、2959042、2957450 漏了新地島與新西伯利亞群島，以同政權 2851158 v122 的島嶼補上（provenance.unclip.arcticIslandsPatch 有註記）。
- 伊朗 1939+：框外取 2694890；英蘇佔領區手繪分界東端由 61°E 延伸到 64°E。
- 亞洲鄰國 1908～1937（OHM 固定版本，見 requests/R2 各檔 geometryLocator）：大清、中華民國（北京政府→國民政府）、博克多汗國（外蒙古）、蒙古人民共和國、唐努烏梁海（圖瓦）、西藏、滿洲國、大韓帝國、日本、遠東共和國、布哈拉（酋長國→人民蘇維埃共和國）、希瓦（汗國→花剌子模人民蘇維埃共和國）、北庫頁島日本佔領區、波斯→伊朗、阿富汗（酋長國→王國）。在 1937-07-07／1939-01-01 與既有紀錄無縫銜接（幾何差異 0）。
- 優先序：開發庫既有（不撤回）紀錄 > 分離政權／保護國／佔領 > 俄國與伊朗 > 大鄰國；低優先在高優先起訖日切段，幾何幾乎不變的相鄰段合併。
