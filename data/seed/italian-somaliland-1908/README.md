# italian-somaliland-1908（義屬索馬利蘭 1908–1920 補上內陸）

日期：2026-11-14。狀態：**已寫入開發庫**（寫入前備份 `~/wl-db-backups/20261114-155134-pre-italian-somaliland-1908.dump`）。只寫開發庫，沒有寫正式庫。

來由：比對期初國界時，兩套地圖集都把義屬索馬利蘭畫成深入內陸的一整塊，資料庫 1908–1920 年那一筆卻只有貝納迪爾沿岸 10,697 平方公里。查資料庫後確認：1920 年起那一筆有 172,815 平方公里，兩者相差的內陸約 16 萬平方公里在 1908–1920 年**沒有任何紀錄涵蓋**（是空白，不是算給衣索比亞）。

做法（I5：撤回＋重寫）：撤回 1908-01-01～1920-01-01 那一筆，改用資料庫裡 1920-01-01 起那一筆的形狀重寫（與衣索比亞的紀錄只重疊 0.6 平方公里）。附 Shepherd 1911 與劍橋 1924 年版兩筆引文（各 B 級、不同家族），現在是已查證。

還沒解決的：

- **內陸界線只是大致位置。** 義大利與衣索比亞 1908-05-16 簽了邊界協定，但協定原文還沒取得；查到的二手說明指出那條線一直沒有實地勘定。地圖集的比例尺也只能確認「有內陸」，不能確認界線位置。
- 1908-01-01 到 1908-05-16 之間（協定之前）用的是同一個形狀，沒有另外處理。
- OHM 把含內陸的形狀起日記為 1920，原因沒有查到。
- 1924、1927、1928 年的三次變動（朱巴蘭移交、併入兩個蘇丹國等）仍然沒有對應的事件。
