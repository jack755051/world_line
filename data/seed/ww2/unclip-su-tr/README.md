# unclip-su-tr（蘇聯、土耳其國界補完整；DRAFT，待 Tai 檢查）

問題：歐陸試驗各批（borders-1938-1940 到 borders-1943-1945）用 `FRAME = box(-12, 34, 42, 72)` 裁切，
蘇聯 22 筆、土耳其 2 筆紀錄在東經 42 度被切開：蘇聯亞洲部分（高加索東部、中亞、西伯利亞、遠東）與東經 42 度以東的歐俄、
土耳其安納托利亞東部都缺漏。

做法（撤回再新增，**只寫入開發庫** worldline-borders-dev／API 127.0.0.1:5052）：
- `build/build.py`：讀唯讀 SQL 匯出的既有紀錄（/tmp/sutr.txt）；用當時抓取的同一 OHM raw 檔（版本號逐筆核對與紀錄的 ohm_version 相同），
  全球框重組＋ Natural Earth 10m 陸地裁切，只取「歐陸框外部分」併回既有幾何；框外部分簡化到約 2 km（0.02 度）並略去小於 1e-3 平方度的小島（世界縮放用，控制資料量）。框內幾何原封不動（含已扣掉的德國、芬蘭、羅馬尼亞等佔領區），inside_change 全為 0。
- 與同期其他政權（/tmp/others.txt，亞洲第一批等框外紀錄）重疊處扣除：黑龍江／烏蘇里江江中島與滿洲國重疊約 0.05 平方度，依既有滿洲國紀錄扣除
  （1926～1937 那筆也一併扣除，該處在 1932 年前略有空白，簡化）；其他只有共有邊界上的細碎重疊。扣除後重疊 0。
- 框外線段授權：全部 untagged（OHM CC0），不需要新增出處標示；原紀錄的 geometryLicense／attribution 沿用。
- `build/make_requests.py`：每筆一個撤回（01-NNa）＋一個新增（01-NNb），欄位與原紀錄相同（政權、期間、層級、起訖事件、來源、OHM 版本與 raw 日期），
  geometryLocator 加註「完整，不受歐陸框裁切」，provenance.unclip 記錄被取代的紀錄 id 與做法，note 加註修正日期。
- 送出：`python3 send_seed.py [--send] --base http://127.0.0.1:5052 ...`（預設 dry-run；拒絕 5051）。
