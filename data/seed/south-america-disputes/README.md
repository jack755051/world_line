查證後更正先前的說法：比對地圖集時記下「資料庫把查科大半算給巴拉圭」，那是看圖時被上層圖徵蓋住造成的誤判。資料庫裡玻利維亞與巴拉圭的紀錄在查科本來就重疊 327,065 平方公里，資料集已經把兩方的主張都畫了，只是沒有標成爭議。

出處與限制：

- 各方「有這個主張」的依據是 1910 年前後的兩套地圖集（Shepherd 1911 pp. 214–215、劍橋 1924 年版 Map 135，各 B 級），寫在各方的主張說明裡。巴拉圭對查科的主張目前沒有 A／B 出處。
- 所有範圍都取自資料集，沒有另外查證。
- 亞馬遜上游只處理到 1916-07-15；之後厄瓜多的三筆紀錄（到 1942 年里約議定書）還沒有比對出處，沒有標爭議。秘魯、哥倫比亞的主張範圍沒有可用的形狀。
- `effective` 都留空：沒有查當時實際由誰管轄。
