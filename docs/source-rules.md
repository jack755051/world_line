# 資料來源規則

日期：2026-11-13。狀態：**已核准**（Tai 2026-11-13「D1–D6 都照建議」）。憲法 R7／I6 已指向本文；ARCHITECTURE 中與本文不同的舊條文以本文為準。
適用：專案內所有歷史資料——疆界、控制、政權、事件、首都、陣營、元首任期、人物生平、戰役。
本文把散在憲法、ARCHITECTURE、各批 README 的來源規則收成一份，並補上原本沒有規則的資料種類。與現行條文不同之處集中列在 §8。

## 1. 四件事分開判定

每一筆資料都要回答四個問題。四者互不換算，其中一項的結果不得用來調整另一項。

| 問題 | 判定什麼 | 結果 |
|---|---|---|
| 來源等級 | 這份出處本身是什麼性質 | A／B／C／X |
| 授權 | 這份出處的圖形或圖片能不能轉載 | 可轉載／只能引用 |
| 獨立來源 | 有幾方各自這樣說、是誰說的 | 家族數；己方／對手方／第三方 |
| 可信程度 | 這一筆資料目前查到什麼程度 | 已查證／待查證／推估／說法衝突／查無 |

## 2. 來源等級

等級評的是**實際讀到的那份文件**，不是它引用的書。評定後不因來源數目或其他原因更動。每個來源登記時寫明評等依據。

| 等級 | 定義 | 疆界、政權、事件 | 人物 | 戰役 |
|---|---|---|---|---|
| A | 當事機關的原始文件，或國家級權威機構的編纂物 | 條約原文、政府公報、憲法與法令、外交文書彙編 | 官方檔案、國家級傳記辭典、權威人名檔 | 原始作戰檔案、國家機構編的官方戰史 |
| B | 具名學者或學術機構的研究；第三方當時的官方紀錄 | 學術專書、期刊論文、學術地圖集 | 學術專書、具名作者的百科條目 | 學術專書與論文、第三方外交電報、當事人為官方撰寫的戰後紀錄 |
| C | 合法、有具名作者或出版機構，但不到 B | 通俗歷史、機構網站的介紹文 | 同左 | 同左 |
| X | 不收 | Wikipedia、Wikidata（例外見下方「C 級補充區」）、百度百科、個人網站、論壇、無署名內容、只標「自製」的地圖、被接管的網域 | 同左 | 同左 |

- **資料集不是出處。** OpenHistoricalMap 等資料集只提供幾何（形狀），不能當作「這條疆界在這一天生效」的出處。
- **索引不是出處。** Wikipedia 列表、Wikidata 編號只能用來找人、找候選值，值本身要另外用 A／B 來源核對。
- **網域字樣規則有誤判例外**（Tai 2026-11-14）。網域裡有一段剛好是 forum、bbs、blog、wiki 等字樣就不收，但字樣不是那個意思時（例：`bbs.bt` 是不丹國家廣播公司 Bhutan Broadcasting Service），列進 `source-policy.json` 的 `bannedHostLabelExceptions` 就只免除字樣規則；來源本身照常評等，指名禁用的網域照擋。
- **轉錄本記 B。** 讀到的不是原件，而是第三方逐字轉錄的版本時，原件是 A 的一律記成 B，並在評等依據寫明是轉錄本。
- **Wikisource 是轉錄本，不是 Wikipedia**（Tai 2026-11-14）。只在同時符合三個條件時才收，等級照上一條記 B：轉錄的是官方文件或原始文獻；該頁附原書掃描可以對照（有 Index 頁）；引文在頁面上逐字找得到。Wikipedia、Wikidata 仍然不收，只當索引。
- 禁用網域只維護一份清單（`SourcePolicy`），所有檢查程式共用。現在有 6 份不同的清單。
- **C 級補充區**（Tai 2026-11-18）。Wikipedia、Wikidata 只能在 C 級補充區裡當 C 級來源，主內容永遠不收。人物生平是 `person.supplementC`；戰役若要用，也只能放在同樣獨立的補充區。條件：
  - 先用盡 A／B 來源（人物生平：分層補查的第二階段）仍不夠，才可以用，而且只拿來補到最低篇幅，以及補起迄日。
  - 主段落、職位、角色不引用補充區。最低標準與查證程度只算 A／B。
  - 每一條都附來源網址，並附一段逐字引文（≤80 字）。
  - 只有 C 的日期一律標「待查證」，不算已查證。
  - **A／B 為準**：C 和既有 A／B 的日期、職位、地點、數字、任期衝突時，以 A／B 為準。衝突的 C 自動刪除，或只留成註記（`conflictsWithAB`，附 A／B 出處），不當事實顯示。
  - C 句子裡的年份、數字、專名要出現在它的引文裡，沒有的刪掉。
  - 之後找到 A／B，就取代對應的 C。
  - 匯入或顯示時，加註「未查證・維基百科補充」。
  - 拿 Wikidata 當索引找人、找網址，照舊可以；那不算出處。

## 3. 授權

授權只管「能不能把這份來源的圖形或圖片放進產品」，不管能不能引用它的事實。

- 疆界、控制區的幾何，以及人物照片：只限公有領域或 CC 授權，逐筆記錄授權與姓名標示。
- 非商業或禁止轉散布的資料（CShapes、CHGIS 等）：只用於對照，不寫入。
- 引用事實、抄錄短引文（80 字以內）不受此限。

## 4. 獨立來源

- 同一機構、同一套底稿、或互相轉引的來源算同一個**家族**，只算一個獨立來源。
- 不為了湊數把同一脈絡的來源拆開。
- 涉及敵對雙方的資料（戰役、佔領、控制），另外記錄來源是**己方、對手方或第三方**。

## 5. 可信程度

| 可信程度 | 條件 | 畫面 |
|---|---|---|
| 已查證 | 一筆 A，或兩個獨立家族的 B，引文逐字核對通過，說法一致 | 正常顯示 |
| 待查證 | 有 A／B 出處，但不到上一列的門檻 | 顯示並標「待查證」 |
| 推估 | 位置或形狀由讀圖、內插、演算法或文字地名連線得出 | 外觀與有出處者可區分，標「推估」 |
| 說法衝突 | 兩個合格來源說法不同 | 兩個都列，不自己選 |
| 查無 | 只有 C／X、沒有出處，或引文沒通過核對 | 不顯示；留在資料建置檔當線索 |

補充三條：

1. **對手方的 A 不能單獨成立。** 關於某一方的事實（編制、位置、傷亡），只有對手方來源時，不論等級都是待查證。
2. **欄位分開判定。** 一件事與它的精確日期、地點、數字，各自看有幾個來源支持。支持較少的欄位降低精度或列為候選，不整筆丟掉。
3. **期間分開判定。** 出處只能支撐部分期間時，依時期拆段（憲法 I1）。
4. **合格出處優先**（Tai 2026-11-14）。不合格出處（C／X，或低於該類資料的最低等級）與合格出處說法不同時，以合格出處為準，不算說法衝突；說法衝突只發生在兩個合格出處之間。沿用 2026-11-13 禁用網域替換「以新來源為準」的做法。
5. **已寫入但不合格的人物生平欄位**（Tai 2026-11-14）。只剩 C／X 出處的人物生平欄位，先補查；補查後仍查無者照上表「查無」撤回，不顯示，補到合格出處再寫回。姓名不可空白，保留並標待查證。將領生平收具名 C，不在此列。其他資料種類照 §6 各自的規定（例：主權疆界只有資料集者標待查證）。

## 6. 能不能寫進資料庫

共通條件：**來源等級達到該類資料的最低等級，而且引文通過逐字核對**。達到條件就寫入，可信程度照 §5 標示。只有一個來源不影響能不能寫入。沒有任何出處的資料不寫入。

| 資料種類 | 最低等級 | 這一類的特別規定 |
|---|---|---|
| 主權疆界 | A／B | 幾何可取自開放資料集；**起訖日與主張本身**要另有 A／B 出處。只有資料集時，標待查證。連資料集形狀與出處都沒有的地區留白，呈現「主權資料缺」，不建立紀錄（憲法 R10）。同一塊地有不只一方主張時，各方各記一筆並用「主權爭議」串起來；查無出處的一方只記有這個主張，不畫範圍（憲法 R6）。地圖集圖版是某一年的快照：只靠它查證的紀錄不可延續到圖版年代之後太久，1910 年前後的圖版以 1912-01-01 為界切段，後段另找出處（憲法 I1；Tai 2026-11-14） |
| 實際控制 | A／B | 主要出處必須是有出版者、圖號的地圖。找不到就呈現「控制資料缺」，不用任何控制類型代替 |
| 政權（名稱、起訖） | A／B | 自稱名稱要有出處。目前取自資料集的，標待查證 |
| 事件 | A／B | 沒有引文的事件不寫入 |
| 首都 | A／B | 出處接到來源登記，不用自由文字 |
| 陣營 | A | 只依最嚴謹的正式加入文件；參戰日等只作補充 |
| 元首、首腦任期 | A／B | 出處接到來源登記並帶等級，不用自由文字。**迄日記繼任者就任日**，讓任期首尾相接（Tai 2026-11-14）：來源記本人辭職／卸任早一兩天時不改日期、不算說法衝突，在引文備註寫明「迄日依繼任者就任日；來源記本人卸任為某日」。依政權存在期間截斷的起訖日同樣照留，備註寫明是截斷 |
| 人物生平 | A／B；將領可到具名 C | C 級在畫面上標示等級 |
| 戰役（部隊、位置、前線、交戰、據點） | A／B | 讀圖得到的位置一律是推估；部隊最細到師。戰役頁上的推導圖形（內插、自動生成的控制區與前線）與示意圖形（箭頭、包圍圈、航線）不是資料：不寫入、不可查詢；示意圖形須掛在一段有 A／B 出處的敘述上（憲法 Decision 5，2026-11-15） |
| 一級行政區 | A／B | 同主權疆界 |

### 6a. 讀圖配準門檻（戰役態勢圖）

門檻管的是「位置畫得多準」，不是來源等級，也不是可信程度：圖的等級照第 2 節評，讀圖得到的位置不論哪一級門檻都是推估。

| 圖的種類 | 判定（配準前依圖本身決定，寫進讀圖檔） | 門檻（留一法 95 百分位） | 可以用在哪 |
|---|---|---|---|
| 一般態勢圖 | 預設 | ≤ 2 公里（2026-11-13） | 部隊位置、前線頂點 |
| 全戰區圖 | 圖幅橫跨超過 200 公里，畫的是集團軍層級的配置 | ≤ 15 公里（Tai 2026-11-17） | 只有集團軍群、集團軍、軍、裝甲師的位置（軍級於 2026-11-17 同日補入）。不用於前線，不用來推算領地 |

- 分級不得因為一張圖過不了 2 公里才改；沒有在配準前決定的，整張圖只供參考。
- 沒過門檻的圖只供參考，不上圖。
- 配準過門檻只代表「圖上的點換成經緯度」夠準，不代表圖上的單位方框就是部隊位置。地圖集常把方框擺在看得清楚的地方（箭頭起點、後方空白處）。方框位置和同一張圖的戰線、或和 A 級文字出處差距超過標示精度時，那張圖的方框都不取（敦克爾克：西點地圖集第 11、12 號圖）。
- 畫面上每個讀圖位置都顯示精度（配準誤差＋標註框誤差）；全戰區圖另外註明「只表示大致的配置區」。
- 工具：`tools/battles/georef.py`（全戰區圖用仿射模型，因為這類圖的控制點少）。

## 7. 查不到的時候

- 照實標待查證或查無，並記下試過哪些來源、卡在哪裡、哪本紙本書可以補。
- 不放寬 §2、§4 來換取「已查證」。
- 不用預設值填空（例：起訖日填成戰役起訖日）。
- **精確日期查不到時，降低日期精度**（Tai 2026-11-14）。做法：
  - 事件：出處只能確定到月或年，就把事件記成月或年的精度，並在說明寫明原因；不要為了湊到「日」而採用不合格的出處，也不要因此整筆不寫。
  - 國界：資料庫裡國界的日期取自資料集而且不可改，所以另外標示「起始日可由出處確定到月／年」（`sovereignty_record_links.start_date_precision`），畫面照實顯示「起始日只確定到年」。
  - 降低精度只處理「哪一天不確定」。如果連「這件事有沒有發生、有沒有生效」都沒有出處（例：只有條約本文，沒有批准或移交的紀錄），那是缺出處，不是精度問題，仍然不寫。
- 更正一律「撤回原紀錄＋寫入新紀錄」，不刪除（憲法 I5）。
