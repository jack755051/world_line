# labrador-dispute（拉布拉多內陸：加拿大與紐芬蘭兩方主張並存）

日期：2026-11-14。狀態：**已寫入開發庫**（寫入前備份在 `~/wl-db-backups/`，檔名結尾 `-pre-labrador-dispute.dump`）。只寫開發庫。這是「主權爭議」（憲法 R6、I3）的第一筆實際資料。

來由：匯入時（`ohm-b1-north-america-1908-1945`）加拿大與紐芬蘭的資料集範圍在拉布拉多內陸重疊約 20 萬平方公里，當時兩邊都扣掉留白、待 Tai 決定。Tai 2026-11-14 決定：有爭議的記成多筆主張並標爭議。

寫了什麼：

| 項目 | 內容 |
|---|---|
| 出處 | The Canada Year Book 1926, p. 1036（加拿大自治領統計局，A 級） |
| 事件 | 1927-03-01 樞密院司法委員會裁決拉布拉多邊界（已查證） |
| 主權紀錄 | 加拿大 3 筆、紐芬蘭 2 筆（1908-01-01～1927-03-11）各自加回爭議範圍，撤回重寫 |
| 引文 | 年鑑引文附在加拿大 1908 年那一筆 |
| 主權爭議 | `labrador-boundary-before-1927`，串起兩方五筆紀錄 |

爭議範圍：紐芬蘭資料集關係的完整範圍扣掉資料庫裡紐芬蘭原有的部分，也就是匯入時被扣掉的那一塊。1908-01-01～1927-01-01 約 20.2 萬平方公里，1927-01-01～1927-03-11 約 23.9 萬（資料集把裁決後的形狀起日記為「1927」）。

可信程度：加拿大三筆是已查證（1908 年那筆有兩套地圖集、年鑑與裁決書；後兩筆沿用）。紐芬蘭兩筆原本是待查證，補上裁決書後是已查證。

2026-11-14 補上裁決書本文（請求檔 06–12，`build/add_jcpc.py`）：Tai 用瀏覽器下載 BAILII 的掃描 PDF（[1927] UKPC 25，26 頁）後提供。裁決書 pp. 9–10 逐字載明雙方主張，p. 23 是裁決結論。做了：登記為出處（A 級）；加拿大 1908 年那筆、紐芬蘭兩筆各附一筆引文；裁決事件與主權爭議撤回重寫，改引裁決書。紐芬蘭兩筆因此從待查證變成已查證。下面「還沒解決的」第一、二點已經解決，保留原文作紀錄。

引文是 Claude 看掃描圖逐字抄錄的（PDF 沒有文字層），待複核。

還沒解決的：

- **紐芬蘭一方的主張只有對手方出處。** 年鑑是加拿大的官方出版品；紐芬蘭自己的出處和裁決本文都沒取得（BAILII 有防機器人機制，沒有繞過；Heritage Newfoundland 連線逾時）。照規則，只有對手方出處時不論等級都是待查證。
- **紐芬蘭原有的兩筆地圖集引文沒有接回來。** 地圖集畫的紐芬蘭只有沿岸；現在這筆紀錄畫的是含內陸的主張範圍，不能再說「與圖相符」。已從 `data/seed/atlases-1910/citations.json` 移除。
- **爭議範圍與年鑑的數字不同。** 年鑑說移交 112,400 平方英里（約 29 萬平方公里），資料集的重疊範圍約 20 萬。範圍取自資料集，沒有另外查證。
- **裁決日與資料集換段日差十天。** 裁決是 1927-03-01；資料庫照資料集在 1927-03-11 換段，原因沒查到，所以裁決事件沒有接成紀錄的起訖事件。
- `effective`（當時實際生效的是哪一方）兩方都留空：沒有查當時內陸實際由誰管轄。
- 主張紀錄被撤回重寫時，爭議要跟著撤回重建（主張列指向的是紀錄編號）。
