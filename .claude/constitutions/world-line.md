# Business Constitution: World Line — 歷史地圖 GIS 業務憲法

> 這份文件不是 PRD（不寫 tech stack / API / Schema / 頁面）。這份文件不是 Charter（不寫範圍邊界 / 分批計畫）。
> 它只回答一件事：**這個「以 GIS/地圖呈現世界歷史」的業務領域，規矩是什麼**。
> 本文規則跨時代通用（二戰、近代、古代皆適用）；舉例中的三國、唐朝、二戰案例只是說明，不代表規則只適用於該時代。

## 1. 業務目的 (Business Purpose)

- **這個領域服務的對象**：「希望先給自己，在給教育」
- **這個領域要解決的核心問題**：「傳統的歷史知識在書本中傳遞時是透過拆解來聚焦在某個時間…但我希望能實現的目標是，當東方在某個時期，西方也在發展，比如說中國唐朝時，有了跟大食的貿易，對於中國來說是大食，但是對於阿拉伯帝國來說呢？因為傳統的書本會依據視角來拓展知識，但我希望的最終目的是能夠縱覽世界，所以才希望以gis跟地圖資訊的方式來輔助」
- **明確不在這個領域內的問題**：
  - 「不做遊戲化虛構劇情」（永久排除）
  - 「也不做未來推測」（永久排除）
  - ⚠️「史前歷史先等整個完成後再處理」——**這是階段性延後，不是永久排除**，性質與上述兩項不同，特此區分標註。

**階段實施順序**（**AI 提案・使用者拍板**，Tier 2，grill-me 2026-10-02 Q1 + Q11）：由近而遠、依史料可得性往回推。產品核心目標不變，只換起點（見 §7 Decision 2）。

1. 二戰（全球、國家／控制區層級）
2. 二戰深化（戰線層級、部隊層級、第二個以上的歷史維度，見 R5）
3. 近代延伸（如一戰、19 世紀）
4. 古代（中國史 → 世界史）
5. 單一國家史（如台灣史）

**第一階段範圍**（**AI 提案・使用者拍板**，Tier 2，Q4）：時間 1937-07 ～ 1945-09，涵蓋全球所有戰區。1931 年起的相關資料（如滿洲國）可往前檢視，但不保證完整。
  - 「涵蓋全球」指主權軸全球都要有；實際控制軸找不到合格來源的戰區（依 2026-10-27 史料調查，例如東非、中東、法屬印度支那、泰國）第一階段只做主權，控制以「控制資料缺」呈現（見 R9）（**AI 提案・使用者拍板**，Tier 2，2026-10-27，使用者選 A：§1 維持全球，不縮小戰區）。

## 3. 核心業務規則 (Core Business Rules)

- **R1**：「第一階段只呈現到朝代/國家層級，如果完成宏觀的史觀後在繼續深入到城市的發展。」
  - 二戰的層級劃分（**AI 提案・使用者拍板**，Tier 2，Q3）：第一階段為「國家／控制區層級」。使用者原話：「我先做Ａ但是BC幫我寄路再後續的階段上」——**戰線層級**（獨立描繪的週級戰線、軍團／集團軍級進軍）與**部隊層級**（師級軌跡、日級精度）屬二戰深化階段，**不是永久排除**。
- **R2**：「規則部分，我希望疆域是能夠同時存在的，就我剛剛所說，我希望在唐朝時，我可以看到唐朝的版圖跟阿拉伯帝國的疆域，甚至是歐洲當時的帝國跟朝代。」
- **R3**：「但也可以當我聚焦到某個政權時，來看該政權與其他該時段政權的互動」
- **R4**（**AI 提案・使用者拍板**，Tier 2，2026-08-29）：系統需支援中文／英文雙語呈現，涵蓋領域內容本身（政權名稱、事件敘事、爭議點等），不只是介面文字——避免使用者切換語言後內容仍停留在單一語言的體驗落差。語言擴充性（未來若需要中英文以外的語言）留待實際需求出現時評估，不預先設計成無限語言；資料結構須為可擴充設計（細節見 PRD），但不代表現在就要支援兩種以外的語言。
- **R5**（**AI 提案・使用者拍板**，Tier 2，grill-me 2026-10-02 Q6）：系統以「多個歷史維度」呈現歷史動能——政治／軍事之外，經濟／後勤、人口／人道、宗教、文化、疾病等維度可在同一時間軸上切換觀察。源自使用者原話：「另外也可以除了單純的朝代/帝國變遷，後續實現可能宗教/語言/科技/文化/疾病/飲食等等的傳播跟分合來處理」。**第一階段只交付政治／軍事維度**；第二個維度上線時才需要維度切換能力。
- **R6**（**AI 提案・使用者拍板**，Tier 2，Q2 + Q9）：一塊土地的歸屬分為兩個獨立的軸——
  - **主權**：以「主權主張」記錄，同一時間同一地區可有多筆主張並存，每筆須標明主張方與承認方；預設呈現「當時實際生效」的那一筆，其餘以多重視角／爭議並存呈現，系統不裁判主權正當性。「實際生效」在個別案例有爭議時，逐案記錄爭議點，不建立通則。
  - **實際控制**：控制類型分為直接統治、軍事佔領、傀儡代管、不完全控制、交戰中（見 §6）。同一地區同一時間可有多筆控制紀錄（例：兩方皆為「不完全控制」）。
  - 戰線為控制區之間的邊界，不是獨立的業務實體（第一階段）。
- **R7**（**AI 提案・使用者拍板**，Tier 2，Q8）：史料來源政策——
  - 主權軸可採用開放授權的既有資料集，逐筆標註來源。
  - 控制軸以手動數位化取得，底圖只限「有明確出版者／出處，且為公有領域或 CC 授權」的地圖；每筆紀錄須指出所依據的地圖集與頁碼／圖號。
  - 來源僅標示「自製」、未說明依據者，一律不採用。
- **R8**（**AI 提案・使用者拍板**，Tier 2，Q10）：**多重視角不等於相對主義**。數字（如傷亡）、命名、定性等有學術爭議的部分，以多觀點並列呈現；但觀點須有合格史料支撐（見 §6「合格史料」）才能入列。已由史料確立的事實（事件本身是否發生）不開放並列，否認論不構成一個觀點。暴行事件（如南京大屠殺、猶太大屠殺）屬政治／軍事維度的事件，第一階段即納入。
- **R9**（**AI 提案・使用者拍板**，Tier 2，2026-10-27，使用者回覆「好」）：某地區某時間找不到合格來源可判斷實際控制時，以「控制資料缺」呈現，**不可用任何一種控制類型代替**（尤其不可標為「不完全控制」）。理由：「不完全控制」是有史料支撐的狀態，用它填補缺口等於把「沒有資料」呈現成史實，與 R8 精神衝突。日後取得合格來源時補上控制紀錄即可。
  - **例外：未捲入戰事的地區**（**AI 提案・使用者拍板**，Tier 2，2026-10-27，使用者選 A）：中立國、未受戰事波及的殖民地等地區不會有戰場地圖，其實際控制以主權推定（見 §6「依主權推定控制」），不呈現為控制資料缺。推定的控制須與有來源的控制紀錄在呈現上可區分，不可冒充史料。曾發生戰事或佔領的地區不適用本例外。

## 4. 業務狀態機 (State Machines)

### 政權 (Regime)

**分裂／禪讓／滅亡**——基於「三國」案例，使用者確認（「對，主要就是這樣」）以下狀態轉換成立：

```
存續(漢朝) ──分裂──> 存續(曹魏) + 存續(蜀漢) + 存續(東吳)
                          │             │            │
                       被取代        被滅亡        被滅亡
                       (禪讓)       (亡於曹魏)    (亡於西晉)
                          ↓                          ↓
                      存續(西晉) <───────────── 統一
```

**流亡／被併吞／復國**（**AI 提案・使用者拍板**，Tier 2，grill-me 2026-10-02 Q13）：

```
存續 ──流亡──> 流亡（失去本土，政府在外延續主張；例：波蘭、荷蘭、挪威流亡倫敦）
存續 ──被併吞──> 被併吞（非武力滅亡，經條約或脅迫併入他國；例：1938 德奧合併、1940 波羅的海三國）
流亡 / 被併吞 ──復國──> 存續（恢復對本土的實際管轄；例：1945 奧地利）
存續 ──政體更替──> 存續（新政權；例：1940-07 法蘭西第三共和 → 法蘭西國〔維琪〕）
```

**合法轉換**：
- 存續 → 分裂：政權分裂同時產生多個新政權（例：漢朝 → 曹魏／蜀漢／東吳）
- 存續 → 被取代（禪讓）：政權被和平轉移方式取代（例：曹魏 → 西晉）
- 存續 → 被滅亡：政權被武力消滅（例：蜀漢被曹魏滅亡、東吳被西晉滅亡）
- 存續 → 流亡：失去本土，政府在外延續主張
- 存續 → 被併吞：經條約或脅迫併入他國
- 流亡／被併吞 → 存續（復國）：恢復對本土的實際管轄
- 存續 → 政體更替（**AI 提案・使用者拍板**，Tier 2，2026-10-27，使用者選 A）：政權未分裂、未被外力消滅或併吞，而是經內部程序改變國號與體制，原政權終止、產生一個新政權（例：1940-07 法國國民議會授權貝當，第三共和 → 法蘭西國）。理由：更替前後兩者在主權主張與承認方上的處境不同，須為不同政權才能呈現

> 「取代跟消滅應該是兩種不同的定義」——**被取代（禪讓）與被滅亡，須為兩種不同的狀態轉換**，不可合併。同一原則延伸：**被併吞與被滅亡也是兩種不同轉換**，不可合併；**政體更替與被取代（禪讓）也是兩種不同轉換**——禪讓是政權移交給另一個既有勢力，政體更替是同一國家內部改制。

**不屬於政權狀態的情況**（**AI 提案・使用者拍板**，Tier 2，Q13）：
- **佔領**屬 R6 的「實際控制」軸。被佔領的政權（例：1945 年後的日本）在狀態機上仍為「存續」。
- **投降、停戰**是事件，以歷史事件記錄。
- 政權是否在某時點終止有史學／法學爭議者（例：納粹德國 1945 年是終止還是國家延續），記錄為爭議點，狀態機不裁定。

**傳承關係鏈**（**AI 提案・使用者拍板**，Tier 2，grill-me 2026-08-25）：每個因「分裂」、「被取代（禪讓）」或「政體更替」而產生的政權，均須記錄其前身政權；獨立建國則無前身。若政權以「被滅亡」方式終止，須記錄消滅方政權。此規則與 §6「正式朝代」術語互為表裡：轉換邊本身是客觀事實，「正式朝代」標籤才是史觀立場。

## 5. 不可變約束 (Invariants)

> **AI 提案・使用者拍板**（Tier 2，使用者原話：「那就使用建議…那還有什麼可以繼續延伸的規則？」「三個都選，都是我的不可變的約束」；I1 擴大、I3 改寫、I6 新增經 grill-me 2026-10-02 使用者確認）

- **I1**：每筆疆域資料一定要有時間區間才能存在。「疆域資料」涵蓋 R6 的**主權主張**與**控制紀錄**兩者。
- **I2**：每個政權一定要有自稱名稱才能建立
- **I3**：同一主張方對同一地區、同一時間點，不可同時存在兩筆互相矛盾且都宣稱為正式版本的主權主張；控制紀錄同理（同一控制方、同一地區、同一時間點）——除非明確標記為爭議並存。不同主張方之間的主張並存屬 R6 正常狀態，不受本條限制。
- **I4**：每個政權的他稱代稱都必須能追溯回一個明確存在的自稱政權本體，不可出現找不到對應本體的孤兒代稱資料
- **I5**：所有疆域與政權資料的任何修正，都必須保留原始版本與修改時間戳／修改原因，不可直接覆蓋刪除
- **I6**：每筆主權主張與控制紀錄都必須附來源引用（符合 R7），無來源者不可建立。

## 6. 業務術語表 (Glossary)

| 術語 | 定義 | 不是 |
|---|---|---|
| 政權命名機制 | 「應該會是以自己給予自身名稱爲主，如果在聚焦以某個時代為主觀視角來看時，才依據該視角給予代稱，比如阿拉伯帝國應該在整個歷史中以阿拉伯帝國為稱呼，但如果今天聚焦在唐朝時才以大食做為稱呼，但也需要能夠連結回阿拉伯帝國」 | 不是單一固定名稱；不是只保留他稱而遺失回連自稱的對應關係 |
| 朝代／帝國／國家 | **AI 提案・使用者拍板**（Tier 2，候選 C）：三者不是政權實體固定的屬性，而是「觀察視角」的產物——用現代/後世史學視角觀察稱「朝代」，用政權自身視角觀察稱「帝國」，用同時代其他政權/地緣政治視角觀察稱「國家」，套用 §6 命名機制同一套邏輯的特例 | 不是三個平行、互不相干的獨立分類系統 |
| 地名（城市/山川/地區） | 「地名（城市、山川、地區）我希望也跟1依樣，依據該朝代或者假如今天在縱觀7世紀的時候，唐朝首都稱為長安，那就會以長安為主，頂多後加上括號內的現在的地名。」 | 不是只顯示現代地名；不是只顯示古地名而無現代對照 |
| 正式朝代（史觀主線） | **AI 提案・使用者拍板**（Tier 2，grill-me 2026-08-25）：不是政權的固定分類屬性，而是「史觀主線」的產物——同一套政權轉換事實（分裂／禪讓／滅亡）可以同時被多種不同史觀組成不同的主線序列（例：傳統教科書史觀的漢→魏→晉，或蜀漢正統論史觀的漢→蜀漢→⋯）。核心政權紀錄保持中立，只記錄客觀發生過的轉換動作（見 §4 傳承關係鏈），不判斷誰是「正統」 | 不是政權實體的固定屬性；不是只能存在單一一種「正確」的朝代序列判斷 |
| 政權間互動 | **AI 提案・使用者拍板**（Tier 2，grill-me 2026-08-25，對應 §3 R3）：兩個以上政權之間可被史料佐證的關係或事件，分為兩種性質——(1) 離散事件：有明確起訖時間點的具體事件（戰爭、條約、會戰）；(2) 持續關係：沒有單一時間點、屬於長期狀態的關係（貿易、朝貢、和親、同盟） | 不是政權內部事務；不包含臆測／未發生的假設互動（呼應 §1「不做未來推測」） |
| 史前歷史（排除判準） | **AI 提案・使用者拍板**（Tier 2，2026-08-29）：判準是該文明是否留有「可解讀的自我文字指認」，直接對應 I2（政權建立須有自稱名稱）能否被滿足——有文字紀錄的文明（即使年代久遠，如商代甲骨文）不算史前歷史；無文字系統，或文字系統存在但未被破譯的文明（如三星堆、印度河流域文明、邁諾斯文明），即使物質文明發達、年代較晚，仍歸入 §1「史前歷史」延後範圍，因為無法滿足 I2 | 不是單純以年代早晚劃分；不是以「物質文明是否發達」判斷；不影響已建立政權間的多重史觀主線（見「正式朝代（史觀主線）」），因為這類文明從未被建立為政權 |
| 主權主張 | **AI 提案・使用者拍板**（Tier 2，grill-me 2026-10-02 Q9）：某政權對某地區宣稱擁有法理主權的紀錄，須標明主張方與承認方。同一地區同時可有多筆互相競爭的主張（例：1940 年後的波羅的海三國，蘇聯主張併入、美國等不承認；滿洲國由日本承認、中華民國不承認） | 不是「國際主流承認」的單一版本；不是由系統裁判的「正確主權」 |
| 實際控制 | **AI 提案・使用者拍板**（Tier 2，Q2 + Q5）：某政權在某時間對某地區實際行使支配的狀態，與主權主張獨立。控制類型：**直接統治**、**軍事佔領**、**傀儡代管**、**不完全控制**（如中國戰區日軍「點線佔領」以外的游擊區、敵後根據地）、**交戰中**（雙方爭奪、尚無一方確立控制） | 不是主權；不是政權狀態機的一部分（佔領不改變政權的存續狀態） |
| 戰線 | **AI 提案・使用者拍板**（Tier 2，Q3）：第一階段指相互敵對的控制區之間的邊界，由控制紀錄推導，不獨立記錄。戰線層級的獨立描繪屬二戰深化階段（R1） | 不是第一階段的獨立資料實體；不是部隊進軍路線 |
| 合格史料 | **AI 提案・使用者拍板**（Tier 2，Q10）：可支撐一個觀點入列的史料，包括同時代檔案或官方紀錄、審判紀錄、經同行審查的研究等 | 不是無出處的主張；不是否認已確立事實的論述 |
| 控制資料缺 | **AI 提案・使用者拍板**（Tier 2，2026-10-27，對應 R9）：某地區某時間沒有合格來源可判斷實際控制的狀態，在地圖上與所有控制類型明確區分 | 不是控制類型；不是「不完全控制」或「交戰中」；不是史料 |
| 陣營 | **AI 提案・使用者拍板**（Tier 2，2026-10-28 DESIGN 訪談）：政權在某期間所屬的陣營，分為**軸心**、**同盟**、**共同交戰／合作**、**中立／未結盟**四類。軸心與同盟只依有文件的正式加入（例：三國同盟條約簽署日、聯合國家宣言簽署日或參戰日）判定；未正式加入但與某方共同作戰或合作者（例：芬蘭 1941–44、泰國、維琪法國）歸入「共同交戰／合作」。陣營隨時間變化（例：義大利 1943），每段歸類都須附來源 | 不是系統依交戰關係自行推導；不是對政權正當性或道德的評價 |
| 依主權推定控制 | **AI 提案・使用者拍板**（Tier 2，2026-10-27，對應 R9 例外）：未捲入戰事的地區，以當時生效的主權主張推定其實際控制 | 不是史料；不是控制資料缺；不適用於曾發生戰事或佔領的地區 |
| 史料快照／推估過渡 | **AI 提案・使用者拍板**（Tier 2，Q12）：**史料快照**指有來源支撐、對應特定日期的疆域狀態；來源本身明文確立一整段期間的狀態時（例：停戰協定劃定的分界線，有效至協定失效），整段期間皆屬史料，不必視為推估（**AI 提案・使用者拍板**，Tier 2，2026-10-27，使用者回覆「允許」；僅限來源明文支撐起訖）；**推估過渡**指兩筆快照之間為呈現連續變化而插值產生的中間狀態，不代表史實 | 推估過渡不是史料；不可與史料快照以相同方式呈現 |

## 7. 業務決策 (Business Decisions)

### Decision 1：為何以 GIS/地圖取代傳統書本敘事

- **決策**：以 GIS 地圖方式呈現世界歷史，取代傳統書本依單一視角、按時間拆解敘述歷史的方式。
- **理由**：「「傳統書本依單一視角按時間拆解敘述歷史」本身這就是我的初衷，我希望能夠以世界的視角看歷史，但也可以當我聚焦到某個政權時，來看該政權與其他該時段政權的互動」
- **替代方案（拒絕）**：傳統書本依單一視角、按時間拆解敘述歷史。（⚠️ AI 推論補充，非使用者原句：拒絕原因為「無法同時呈現多個文明/政權在同一時間段的並存發展」）

### Decision 2：第一階段由中國史改為二戰（2026-10-02）

- **決策**（**AI 提案・使用者拍板**，Tier 2，grill-me 2026-10-02 Q1 + Q11）：**換起點，不換產品**。第一階段改為二戰，§1 核心問題（縱覽世界、多視角並存）不變；階段順序改為由近而遠（見 §1）。
- **理由**（T1 原話）：「由於目前使料不好處理，我需要改變策略，時間點換成二戰」
  - 背景（已發生的事實，非新規則）：三國時期的魏／蜀漢疆域在 CHGIS、中研院 CCTS、OpenHistoricalMap 三個管道皆無法取得可用資料（2026-08-31 研究記錄）。
- **替代方案（拒絕）**：
  - 換產品（World Line 改為二戰專題、古代史永久排除）——使用者選擇保留「縱覽世界」核心目標。
  - 二戰後直接回到古代、或先做台灣史——使用者選擇依史料可得性由近而遠。

## 9. 時間 / 期間 / 截止規矩 (Temporal Rules)

- **紀年系統**：「希望以西元為主，但是也能夠保留各國的紀年，比如說日本目前還有的昭和，民國年之類的，或者是中國唐代的可能是武德年號，開元等等」
- **模糊/爭議日期處理**：「允許區間」
- **疆域變化呈現**：「隨時間連續變化，如果可以希望是會有一個拖拉桿，可以拖動時間，類似氣象圖一樣的概念，根據時間來調整衛星雲圖的變化，我希望的是看到疆域的變化」
  - ⚠️ 備註：「拖拉桿」屬互動呈現方式（PRD/UI 層級），本憲法保留的業務規則本體是「疆域必須連續變化呈現，非離散跳轉」。
  - **史料與推估必須區分**（**AI 提案・使用者拍板**，Tier 2，grill-me 2026-10-02 Q12）：時間點位於史料快照日期時呈現史料狀態；位於兩筆快照之間時，插值產生的中間狀態必須明確標示為推估，並可得知最近的史料快照日期（見 §6「史料快照／推估過渡」）。理由：二戰戰線變化快且非線性（如鉗形包圍），均勻插值的中間狀態可能與史實不符。
  - **快照日期由來源決定**（**AI 提案・使用者拍板**，Tier 2，2026-10-27）：有合格來源地圖的日期才建立史料快照，不以固定間隔（如每月）為目標；時間軸仍可拖到任意日期，快照之間依上一條呈現推估。使用者原話：「先依據你的建議，但是後續保留，如果資料可以補回的話就可以實現了」——日後找到更多來源，即可加密快照，最密可達逐月或更細，不需修改本規則。依據：2026-10-27 史料調查（`docs/research/ww2-data-sources.md`），有公有領域來源的「戰區 × 月」約僅 25–35%。
- **時代起訖本身的爭議**（**AI 提案・使用者拍板**，Tier 2，Q4）：時代或戰爭的起訖日期若因史觀不同而有不同說法（例：二戰起點 1931-09-18／1937-07-07／1939-09-01），以爭議點並列，系統不裁定單一起點。
