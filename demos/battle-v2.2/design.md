# 敦克爾克 1940：兩軍對壘示範 v2.2（設計說明）

> 標準註記：這次**沒有重讀** World Line repo、憲章（constitution）或 ARCHITECTURE，也沒有改 repo、沒有部署。文中工時、筆數、誤差、效能數字都是**估計或本機量測**，不代表正式環境。沒查證的歷史細節與來源標「需查證」（見 `NOTES-needs-checking.md`）。畫面與 JSON 全部標「示例，非史料」，不含傷亡數字。

## 1. 怎麼打開
```bash
cd /workspace/battle-demo-v2
python3 -m http.server 8765      # 任何靜態伺服器都可以；不能用 file:// 直接開（要 fetch JSON）
# 瀏覽器開 http://localhost:8765/
```
- 網址參數：`?date=1940-05-26`（停在某日）、`?day=12.5`（停在小數日）、`?autoplay=1`、`?speed=2`、`?legend=0|1`、`?rm=1`（模擬減少動態）、`?data=其他.json`（換資料檔）、`?Lforces=on|off`、`?Leng=auto|on|off`、`?Lplaces=auto|on|off`（圖層初始狀態）、`?glass=0`（關掉毛玻璃，改實色半透明）、`?glass=keep`（不自動降級）。v2.2 新增：`?view=經度,緯度,縮放`（開在指定視角，停止跟隨鏡頭）、`?follow=0`（不跟隨鏡頭）、`?pr=1.5`（強制地圖解析度倍率）；除錯用 `?hide=圖層id,…`、`?dbg=nofill|noline`。
- 操作：空白鍵播放／暫停，←／→ 跳關鍵日，拖時間軸，點符號或交戰點看資訊卡，Esc 關閉。v2.2：滑鼠拖曳／滾輪、觸控雙指可自由平移縮放（縮放 4.6–10.5 級，範圍鎖在戰區 bbox，不旋轉不傾斜），右下有 +／− 鈕。
- 完全離線：MapLibre GL JS 5.24.1、earcut 2.2.4、milsymbol 3.0.5 放在 `vendor/`；Natural Earth 1:10m 陸地、國家、國界、河流已裁成小檔放在 `geo/`（另有 v2.2 產生的 `landc`、`sea`、`graticule`）。不需要網路、地圖圖磚或金鑰，沒有用任何付費圖磚。

## 2. 設計方向
目標是 Tai 說的兩件事：**鋼鐵雄心式兩軍對壘、看得出兵種交互**，加上**零號迴廊 Echo 影片的動態**。這版不沿用舊 P0 外觀，也不沿用 World Line 羊皮紙（依 Tai 這次的指示）。

- **戰情室深色**：海 `#08121a`→`#0c1b26` 徑向漸層，陸地 `#26292a`。讓紅藍疆域成為主角，同時維持地理可讀：海岸線 `#7f97a3` 加淡青外光、經緯網只畫在海上、城市名有深色描邊。
- **疆域是主圖層**：軸心控制區是一個會形變的多邊形（`rgba(92,18,22,.86)`），德國本土呈暗紅，被佔領的法比荷因為底下有盟軍藍，會偏紫紅，一眼分得出「本土」和「新佔領區」。盟軍控制區 `#1d3556` 加 `rgba(52,112,210,.38)`。
- **前線**：疆域邊界在陸地上的那一段就是前線。v2.1 起只用一道 7px 低透明紅光（`rgba(220,70,55,.22)`）加 1.5px 暖白芯，不脈動。停在整日時是實線；內插時改虛線，左上顯示「位置內插・推估」。
- **箭頭（HOI 式）**：每條主攻軸一支，不是每個師一支。尾細頭寬、沿 Catmull-Rom 曲線，箭頭有三角頭；從前一關鍵日開始「長出來」，到達後淡出。v2.1 起配色收斂成兩個陣營色：德軍紅（裝甲 `232,98,82`、步兵 `214,128,114`）、盟軍藍（`104,160,236`），撤退是虛線灰藍，海上撤退是淡藍慢速光點。不再加光暈。
- **部隊符號**：APP-6／MIL-STD-2525，用 milsymbol 產 sprite（啟動時一次，實框和內插用的虛框各一張）。盟軍為友軍藍框矩形、德軍為敵軍紅色菱形；梯隊記號 XX／XXX／XXXX 由 SIDC 決定。右上角小徽章顯示狀態：攻、守、退、圍、降、撤（v2.1 起只在焦點部隊或滑過時出現）。
- **聚合**（v2.1 的做法；v2.2 改成依縮放級數分級＋同格堆疊，見 10.4）：全戰區鏡頭只畫集團軍／軍；鏡頭拉近到敦克爾克一帶（close）時，英國遠征軍展開成第1、2、3軍、第50師、第1陸軍戰車旅，德軍第15、19軍展開成第7、1、2、10裝甲師與 SS 骷髏師。切換用透明度交叉淡入，不跳。符號之間有同幀互推，避免疊成一團。
- **兵種交互**：v2.1 起每個交戰點只畫一個小交叉劍和一道慢慢呼吸的細環（低飽和金 `#d9c48f`）。焦點交戰才從雙方符號拉 1px 細線，不動畫。「兵種配對」標籤（例如「裝甲 vs 裝甲／摩托化步兵」）預設隱藏，滑過或點選才出現，資訊卡裡也有。結果欄刻意留空。
- **動態（v2.1 收斂）**：Tai 認為交戰處的爆炸粒子不適合，所以前線火花、交戰爆裂粒子、閃光全部拿掉，RGB 色偏也拿掉。保留的動態只有：疆域形變、箭頭沿推進軸長出、部隊內插移動、交戰細環呼吸、撤退船隊慢速光點，以及 4 個重大事件（5/13、5/20、5/26、6/4）一道 1px、透明度 0.28 的細環慢慢擴散。事件字卡改成「標題＋一句話」。左上常駐大日期。
- **減少動態**：`prefers-reduced-motion` 或 `?rm=1` 時不內插（每 2 秒跳一個關鍵日），細環不擴散也不呼吸。
- **配色**：兩個陣營色（德軍紅、盟軍藍）＋一個強調色（低飽和金 `#d9c48f`，只用在交戰記號、階段名、時間軸重大事件、選取框）。醋酸片的色調也改成中性暖白 `226,220,206`，不再增加第三、四種顏色。


## 2b. 醋酸片圖層（v2.1，Tai 的建議）
- **由來**：二戰前後的參謀作業圖，常把底圖固定，在上面疊透明醋酸片（acetate / cellophane overlay），用油性筆分別畫敵我態勢、部隊調動、火力或註記；換一張片就換一種資訊，四角用套準十字對齊底圖。這版把同樣的概念搬到畫面上。
- **四層**（由下而上）：
  - **A｜控制區**：疆域＋前線，常駐（就是底片，不能關）。
  - **D｜地名與註記**：城市、河流、國界、海名。自動模式只顯示當日 6–8 個關鍵地名（資料裡的 `places`），「開」才顯示全部。
  - **B｜兵力調動**：箭頭、部隊符號、撤退船隊。
  - **C｜交戰**：交戰記號、焦點交戰的雙方細線；兵種配對標籤滑過或點選才出現。
  （D 放在 B 下面，讓地名不壓住部隊；C 放最上面，讓交戰永遠看得到。）
- **畫法**：每張開著的片都畫成一張「半透明膠片」：整片極淡的中性色調（`226,220,206`，透明度約 0.025；收斂前曾用琥珀、玫紅、淺青三色）、1px 片緣、四角套準十字、右下片名標籤（「B｜兵力調動」）。片緣逐層內縮並錯開幾 px，看起來像疊著的膠片。內容本身不位移，所以和底圖對得準。
- **開關**：右上（手機在地圖下方一列）的圖層膠囊鈕。B 是「開／關」，C、D 是「自動 → 開 → 關」循環。預設 A＋B 開，C、D 自動。
- **自動＝跟當日焦點**：每個關鍵日在資料裡有 `focus`（例如 5/13 `["engagements"]`、5/26 `["places","engagements"]`）。C 交戰在當日焦點有 engagements、而且這段有交戰時才淡入；D 地名在自動模式一直顯示，但只畫當日 `places` 清單裡的地名，換日時交叉淡入。切換用約 0.2 秒淡入淡出。
- 鏡頭移動中（關鍵日之間的鏡頭轉換約 1–2 秒）D 地名片會先淡出、到站再淡入：縮放中的字本來就糊，也能省掉一次整頁縮放貼圖（這是 2x 降速下維持 60 fps 的關鍵）。
- 這套取代了原本想做的「精簡／詳細」切換。師、軍的聚合仍由鏡頭遠近決定，跟圖層開關無關。
- **程式結構**：圖層狀態 `LAYERS`、`layerTarget()`（自動規則）、`stepLayers()`（淡入淡出）和渲染無關。v2.2 改用 MapLibre 時，可以原樣搬過去，改成設定各 MapLibre layer 的 opacity／visibility。

## 2b-2. 焦點強調（v2.1 收斂，回應「資訊太複雜」）
- 每個關鍵日在資料裡有 `focus_units`（例如 5/21 是英軍第1陸軍戰車旅、第50師、德軍第7裝甲師、SS 骷髏師）。父單位在焦點時，子單位也算焦點；反之亦然。
- **焦點部隊**：全尺寸、全透明度、顯示攻／守徽章。
- **非焦點部隊**：縮成 72%、透明度約 40%、不顯示徽章；滑過會暫時恢復。兩個關鍵日之間依焦點清單平滑過渡。
- **箭頭**：每個關鍵日最多 3 支主箭頭，焦點部隊優先、裝甲優先。舊箭頭在下一段的前 30% 淡出。海上撤退航線每個關鍵日最多 1 條。
- **交戰**：焦點交戰（參與部隊含焦點部隊）全強度；其他交戰降到約 38%，也不畫連線。
- **圖例**：桌機和手機都預設收合（左下「圖例」鈕，或用 `?legend=1` 打開）。「虛框＝位置內插」移到 B｜兵力調動底下，另加一列「淡色小符號＝非當日焦點」。

## 2c. 毛玻璃（只用在 UI 面板）
- **v2.2 更新**：時間軸、圖層膠囊、事件字卡、「跟隨鏡頭」鈕改成不模糊的深色半透明底（效能原因，見 10.5）；圖例、資訊卡、交戰配對標籤仍是毛玻璃。下面是 v2.1 的原始設定。
- 事件字卡、圖例、時間軸、圖層膠囊鈕、資訊卡用 `backdrop-filter: blur(6px) saturate(1.25)`，加上 `rgba(14,22,30,.55)` 底和 1px 淡白邊。**地圖本身不加任何模糊。**
- 桌機的時間軸改成浮在地圖底部的玻璃條；鏡頭下緣預留 104px，戰場內容不會被蓋住。手機的時間軸和圖層列仍是獨立一列，不蓋地圖。
- **自動降級**：執行中持續看最近 180 幀，如果有超過 18 幀大於 22ms，就在 `<body>` 加 `no-blur`，改成實色半透明 `rgba(11,17,23,.9)`。也可以用 `?glass=0` 強制。`fps.json` 會記錄每次量測有沒有觸發降級。

## 3. 版面
- **桌機 1440×900**：地圖佔滿時間軸以上的區域；左上大日期與階段名，上方中央黃色「示例，非史料」橫幅，左下可收合圖例（250px），右上圖層膠囊鈕，右側點選後才出現的資訊卡，底部浮動玻璃時間軸（84px，地圖延伸到它下面，但鏡頭預留下緣）。
- **手機 390×844**：上方 64px 標頭（日期、橫幅、「圖例」鈕），中間地圖，地圖下方 42px 圖層列（四顆鈕；自動＝金色虛線框、開＝綠框、關＝變暗），底部 112px 時間軸。圖例預設收合，打開時是地圖底部的兩欄浮層（使用者主動打開才會遮），資訊卡是底部抽屜。標頭和時間軸都不疊在地圖上（`fps.json` 的 `map_box` 有記錄邊界）。手機用另一組鏡頭範圍（`cameras_mobile`），直式畫面不會空掉一半。
- **時間軸標籤不重疊**：按優先序擺（重大事件 > 首尾 > 其他），會和已擺好的標籤重疊就不顯示，刻度還在、可點。桌機顯示「日期＋事件短名」，手機只顯示日期，另有跟著播放頭走的紅色日期籤，並夾在軌道內不出界。量測腳本會檢查重疊（`timeline_label_overlap: false`）。

- **效能數字來自沒有 GPU 的 box**（Mesa llvmpipe）。桌機 1x 的結果見第 4 節表格；實機（特別是中低階手機）要另外量。

- 部隊符號與文字是 sprite（每個縮放等級沒有重新點陣化），放大時尺寸固定、不會變大。
- 5/16 前後盧森堡／馬其諾一帶的軸心區東南角，有一小塊沒被紅藍任一方蓋到的灰色陸地（前線鏈和東側閉合點的接縫），不影響戰役主區，下一版修。

## 10. v2.2：MapLibre 自由縮放、多多邊形前線、去擁擠（2026-11-11，Tai 核准）
### 10.1 架構
- **MapLibre GL JS 5.24.1**（本地 vendor），樣式全部寫在 `app.js`，來源是本地 GeoJSON：`bg`（海色）→ `land`（`landc`，依屬性 `k` 分盟軍藍／英國／其他陸地）→ **`terr` 自訂圖層**（軸心控制區＋包圍圈＋前線）→ `sea`（海面多邊形，把疆域超出海岸的部分蓋掉，延續 v2.1 不做幾何裁切的做法）→ `grat`（7.5 級以上）→ `coast` 1.1px → `rivers`（默茲、斯海爾德、摩澤爾、萊茵、泰晤士等關鍵河流常駐）→ `rivers-other`（7 級以上）→ `borders` → **`battle` 自訂圖層**（D 地名、B 箭頭／部隊／船隊、C 交戰、醋酸片片緣與標籤）。
- **為什麼用 custom layer，不用 GeoJSON source＋`setData`**：疆域、前線、部隊每幀都在內插，`setData` 每幀要在 worker 重新切圖磚，在這台無 GPU 的 box 上 headless 只有約 30 fps。改成兩個 custom layer，用自寫的小型 WebGL 批次器 `js/gl.js`（三組著色器：帶羽化反鋸齒與虛線的線段、填色、sprite 圖集；同種指令合併成一次 draw call），每幀在 CPU 把墨卡托座標投影成螢幕像素。靜態底圖仍交給 MapLibre 的向量圖層。
- 兩個注意點：custom layer 必須保留 MapLibre 的深度測試（只設 `depthMask(false)`），否則不透明的陸地填色會蓋過海面；圖集上傳延到 `flush()`，避免弄亂 MapLibre 的 GL 狀態快取。
- 醋酸片（A／D／B／C）、焦點邏輯、時間軸、事件字卡、毛玻璃面板、`?rm`／`?date`／`?autoplay`／`?data`／`?glass` 都保留。醋酸片的片緣、套準十字、片名標籤改在 WebGL 裡畫（v2.1 是 DOM，疊在 WebGL 上合成太貴）。
### 10.2 跟隨鏡頭
- 播放時預設自動鏡頭（關鍵日的 `camera` bbox → 中心＋縮放，兩日之間 ease 內插，每幀 `jumpTo`）。
- 使用者一拖曳或縮放（`movestart` 帶 `originalEvent`）就停止跟隨，右上出現「◎ 跟隨鏡頭」；按下後 900ms 平滑回到自動鏡頭。
### 10.3 多多邊形前線（schema v2）
- `fronts[]` 每個關鍵日新增：
  - `pockets: [{ id, name_zh, side: "allied", status: "example", ring: [[lng,lat], …] }]`：被圍的盟軍飛地（布洛涅、加萊、里爾）。
  - `control.axis`：產生器算好的軸心控制區 MultiPolygon（前線鏈＋東側閉合，裁 bbox，再挖掉包圍圈）。
  - `front_lines`：MultiLineString（主前線＋各包圍圈外緣）。
- 程式只用前線鏈與 `pockets` 做動畫：包圍圈外緣重採樣成 72 點（逆時針、起點對齊），同一 id 在兩日間逐點內插；只在前一日有＝縮回中心（陷落）；只在後一日有＝整塊出現，外框和名稱淡入。`control.axis` 給檢查工具和之後接 World Line 用。
- 放大到約 7 級以上且 D 片開著時，顯示包圍圈名稱籤。
### 10.4 縮放分級與去擁擠
- **縮放分級**：λ ＝ smoothstep(5.6, 6.0, z) ＋ smoothstep(7.25, 7.6, z)（手機 z 先加 0.9）。0＝集團軍、1＝軍、2＝師／旅。子單位權重依 λ 淡入，沿上級鏈相乘；會被「取代」的上級（克萊斯特裝甲集群、BEF、第19／41／15／16軍、法軍騎兵軍）在子單位出現時淡出；集團軍（德第4、6，法第1、2、9）保留。
- **新增層級**：第19、41軍掛到新加的「克萊斯特裝甲集群」；第15軍 → 第4集團軍；第16軍 → 第6集團軍；法軍騎兵軍 → 第1集團軍；英第50師 → 第3軍。新增師級：德第3、4、5、6、8裝甲師，法第2、3輕機械化師、第18、55、71步兵師；新增英軍第20近衛旅（布洛涅）、第30旅（加萊）。（全部需查證。）
- **同格堆疊**：在螢幕空間依陣營分格（桌機半徑 27px、手機 19px），同格只畫一個「頭」（焦點 > 透明度 > 層級），其他成員淡出，頭的後面畫兩層錯開的淡框，加「+n」數字徽章；點頭的資訊卡列出「同一格」的其他單位。
- 5/13 默茲河渡河箭頭拉長（例如第19軍從阿登森林一路畫到色當），各師位置手擺在河的兩岸；5/16–17 色當缺口與 5/26 包圍圈靠縮放分級＋堆疊收斂。
- D 地名：自動模式顯示當日地名；放大到師級時另外淡淡顯示一級城市；標籤貪婪避碰。
### 10.5 效能調整（無 GPU 環境）
- 時間軸、圖層膠囊、「跟隨鏡頭」鈕、事件字卡改成深色半透明底，不再 `backdrop-filter`：地圖每幀都在動，背後模糊每幀都要重算，在軟體 GL 下約占 8–30% 的幀超時。圖例、資訊卡、交戰配對標籤仍是毛玻璃（只在打開時出現）。事件字卡淡出後設成 `visibility:hidden`（透明度 0 的毛玻璃一樣會每幀重算）。
- 時間軸播放頭、進度條改用 `transform`（scaleX／translateX），不每幀改版面。
- 底圖 GeoJSON source 的 `maxzoom` 從 9 降到 7（`tolerance` 0.3）：放大到 8–10 級時改用 7 級圖磚放大，不必在縮放途中再切三層圖磚。桌機 1x 縮放／平移的慢幀從 40／782 降到約 8／814。代價是 9 級以上海岸線略粗糙（Natural Earth 1:10m 本來就只有這個精度）。
- 量測前暖機：同一瀏覽器第一次開頁的前幾秒會掉幀（GPU 行程編譯著色器），這是之前桌機播放 1x 有 45 幀慢幀的主因，不是戰場繪製本身。
- 拿掉海上經緯網（7.5 級以上才出現）、海岸外光；國界改實線；次要河流 7 級以上才出現。
- 兩段自動降級保留：最近 180 幀有超過 18 幀大於 22ms → ① 關毛玻璃；仍慢 → ② 地圖解析度降到 0.85 倍。`fps.json` 每列記錄是否觸發。
