# denmark-greenland-1944（丹麥 1944-06-17 之後補回格陵蘭與法羅群島）

日期：2026-11-14。狀態：**已寫入開發庫**（寫入前備份在 `~/wl-db-backups/`，檔名結尾 `-pre-denmark-greenland-1944.dump`）。只寫開發庫。

問題：冰島 1944-06-17 獨立後，丹麥的兩筆紀錄（到 1945-05-05、到 1945-10-01）所用的資料集關係只有丹麥本土，格陵蘭（約 215 萬平方公里）與法羅群島沒有任何紀錄。

做法（I5：撤回＋重寫）：兩筆各自加上前一筆丹麥紀錄（1940-04-09～1944-06-17，已不含冰島）在西經 5 度以西的部分，42,682 → 2,194,291 平方公里；起訖事件等欄位照舊。

出處（A 級，逐字核對，附在兩筆紀錄上）：

- FRUS 1941 Europe vol. II, Doc. 40：1941-04-09 格陵蘭防衛協定前言「the sovereignty of Denmark over Greenland is fully recognized」。
- FRUS 1945 Europe vol. IV, Doc. 569：丹麥國王 1945-05-23 正式核准該協定。

還沒解決的：

- 兩筆引文只證明格陵蘭的歸屬。法羅群島（1,329 平方公里，1940–1945 由英國佔領）沒有另外的出處，只是沿用前一筆的形狀。
- 丹麥政府 1941 年曾抗議並宣告該協定無效（FRUS 1941 Doc. 39），但抗議本身也主張「Denmark's sovereign rights over Greenland」；主權歸屬雙方沒有爭議，所以沒有標成主權爭議。
- 格陵蘭由美國協防、法羅群島由英國佔領，屬於實際控制軸，這裡沒有處理。
- 1941 年以前到 1944 年的丹麥紀錄（含格陵蘭）仍只有一套地圖集（劍橋）可證明 1910 年前後的歸屬。
