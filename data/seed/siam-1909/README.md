# siam-1909（1909-07-09 以前的暹羅補上馬來四邦）

日期：2026-11-14。狀態：**已寫入開發庫**（寫入前備份 `~/wl-db-backups/20261114-154620-pre-siam-1909.dump`）。只寫開發庫，沒有寫正式庫。

來由：比對期初國界時發現（`data/seed/source-grading/baseline-borders.csv`），暹羅 1908-01-01～1937-07-07 整段用同一個形狀，是 1909 年之後的暹羅。吉打、吉蘭丹、登嘉樓、玻璃市到 1909-07-09 英暹條約生效才移交英國，在那之前這四邦在資料庫裡沒有任何紀錄涵蓋。

做法（I5：撤回＋重寫）：

| 步驟 | 內容 |
|---|---|
| 撤回 | 暹羅 1908-01-01～1937-07-07 原紀錄 |
| 新增 | 暹羅 1908-01-01～1909-07-09：原形狀＋四邦保護國紀錄的形狀（聯集），515,609 → 554,062 平方公里；結束事件接「英暹條約互換批准書」 |
| 新增 | 暹羅 1909-07-09～1937-07-07：原形狀不動；起始事件接同一事件 |
| 來歷 | `tools/db/classify_sovereignty_origin.py --apply` 重新判定（1937 年那一筆改接新紀錄） |
| 引文 | 1909 年之後那一筆附 Shepherd 1911 pp. 170–171（寫在 `data/seed/atlases-1910/citations.json`） |

結果：1909-07-09 之後那一筆是已查證（起始事件有 A 級出處：FRUS 所附條約本文）。1909-07-09 以前那一筆是待查證。

還沒解決的：

- **1909 年以前那一筆的形狀是推估**。四邦用的是移交之後的邦界；條約同時重劃了邊界，移交前暹羅屬地與霹靂之間的界線可能和這裡畫的不同，還沒查。這一筆沒有附引文，等找到畫出 1909 年以前界線的圖。
- Shepherd 的圖比例尺是 1:40,000,000，半島西岸吉打、玻璃市一帶分辨不出來。劍橋地圖集的中國圖（Map 138）沒有畫到暹羅，所以只有一個地圖集出處。
- 「英暹條約互換批准書」事件的參與方沒有列暹羅（當時誤以為資料庫沒有暹羅的政權，其實代號是 `kingdom-of-thailand`）。要改得撤回事件重寫，連到這個事件的六筆紀錄也要重接，這次沒有做。
