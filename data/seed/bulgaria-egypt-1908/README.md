還沒解決的：

- **自稱名稱沒有出處。** 兩個新政權的自稱原文（Княжество България、الخديوية المصرية）是 Claude 依通行寫法填的，還沒有附出處，也沒有填 Wikidata 編號。
- **形狀沒有另外查證。** 兩筆都沿用下一個政權第一筆的形狀。埃及在 1908–1914 年間的西界與西奈一帶有沒有變動，沒有查；保加利亞 1908 年初的邊界細節也沒有查。
- **A 級引文證明的是地位，不是邊界。** 系統的可信程度是整筆判定，所以這兩筆顯示為已查證；邊界的依據只有資料集加地圖集（保加利亞一套、埃及兩套）。
- 鄂圖曼對埃及的宗主權，出處是英國的文件；鄂圖曼自己的出處還沒取得。
- 埃及當時實際由誰作主（赫迪夫或英國佔領當局）沒有查，`effective` 留空。
- Hertslet 的引用位置只寫文件編號與條號：archive.org 辨識文字的頁碼不可靠。
