# borders-asia-1（亞洲太平洋第一批；DRAFT，待 Tai 檢查）

1937-07-07～1945-09-02：大日本帝國（含朝鮮、臺灣、樺太、千島、關東州、南洋群島）、中華民國（國民政府）、滿洲國（非主權）、
蒙古人民共和國、唐努烏梁海、西藏、泰國（暹羅），以及 1945-08-24 起北緯 38 度以北朝鮮的蘇聯民政署（非主權）。
華北、華中的日本扶植政權（臨時政府、維新政府、蒙疆、汪政權）只建政權與事件，不畫幾何。
**只寫入開發庫**（worldline-borders-dev／API 127.0.0.1:5052）；不寫 appdb_ww2。

- 幾何：固定版本 OHM（`ohm-manifest.json`，Overpass osm_base 2026-10-31T11:30:12Z），東亞框（東經 60～180、南緯 15～北緯 75）＋ Natural Earth 10m 陸地裁切
  （`build/fetch.py`、`build/build.py`）；`build/make_requests.py` 做差集（中國扣滿洲國、日本扣蘇聯民政署）並檢查批內同日不重疊。
  `build/check_existing.py /tmp/exist.txt` 檢查與開發庫既有紀錄（美國、菲律賓自治邦）不重疊（唯讀 SQL 匯出）。
- 事件：有 FRUS 頁碼者已查證（盧溝橋事變、臨時政府、汪政權、珍珠港、蘇聯對日宣戰、蒙古對日宣戰、蘇軍民政署分區、日本降伏）；
  其餘（維新政府、蒙疆、南海島礁版本交替、暹羅改名、泰法戰爭、撣邦與馬來四州、唐努烏梁海併入蘇聯、滿洲國解體、日英開戰）標待查證。
- 衝突圖示：日中（盧溝橋）、日美（珍珠港）、日英（哥打巴魯）、蘇日（樺太北緯 50 度邊界）、蒙日（烏蘭巴托—東京大圓中點）；結束皆為 1945-09-02 降伏文書。
- 送出：`python3 send_seed.py [--send] --base http://127.0.0.1:5052 ...`（預設 dry-run；拒絕 5051）。
