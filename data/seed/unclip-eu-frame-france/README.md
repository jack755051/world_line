# unclip-eu-frame-france（法國 1918–1945 補回阿爾及利亞南部）

日期：2026-11-14。狀態：**已寫入開發庫**（寫入前備份在 `~/wl-db-backups/`，檔名結尾 `-pre-unclip-eu-frame-france.dump`）。只寫開發庫。

問題：1918-11-22 之後法國各政權的 8 筆紀錄，南邊剛好停在北緯 34 度，阿爾及利亞南部約 206 萬平方公里在 1918–1945 年沒有任何紀錄。這是最早的歐陸試驗框 `box(-12, 34, 42, 72)` 裁切留下的（`data/seed/ww2/unclip-su-tr/README.md` 當時就列為「未修」）。OHM 的法國關係本身含整個阿爾及利亞。

對象：法蘭西第三共和（1918-11-22～1940-06-22）、維琪法國、盟軍佔領下的法屬北非、法蘭西民族解放委員會（2 筆）、法蘭西共和國臨時政府（3 筆）。

做法同 `unclip-trial-frame`：框內幾何原封不動（變動 0），框外部分取自 OHM 同一關係後併回；與同期鄰國既有紀錄重疊處扣除（都在 1,300 平方公里以下的邊界細條）。起訖事件、來源等欄位照舊。

**和先前批次不同的地方**：這四個關係（2696299、2747868、2747869、2696301）在 2026-11-13 被 OHM 改過，線上比紀錄記的新兩版，舊版本取不回來。框外部分用的是新版本，已寫在每筆的 `provenance.unclip`。新版本與原紀錄在阿爾及利亞北部（框內）相差約 1,100 平方公里（0.4%），判斷兩版在這一帶沒有實質差別。

沒有查證的：阿爾及利亞的南界是資料集的線（今天的國界）；先前比對地圖集時已記下，1910 年前後的兩套地圖集都沒有畫出這條線。
